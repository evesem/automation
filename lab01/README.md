# Cleanup Script

Bash-скрипт для удаления файлов с указанными расширениями из директории и всех её вложенных директорий.

## Возможности

- Проверяет наличие обязательного аргумента — директории.
- Проверяет существование указанной директории.
- По умолчанию удаляет файлы с расширением `.tmp`.
- Позволяет указать одно или несколько расширений.
- Рекурсивно ищет файлы во всех вложенных директориях.
- Выводит количество удалённых файлов.

## Требования

- Linux/macOS или другая Unix-подобная система
- Bash
- Утилита `find`

## Установка

Сохраните скрипт в файл `cleanup.sh` и сделайте его исполняемым:

```bash
chmod +x cleanup.sh
```

## Использование

- Удаление .tmp файлов

Если расширение не указано, используется .tmp:

```bash
./cleanup.sh /path/to/directory
```

Например:

```bash
./cleanup.sh ./downloads
```

Скрипт удалит все файлы, заканчивающиеся на .tmp, включая файлы во вложенных директориях.

- Удаление файлов с указанным расширением

```bash
./cleanup.sh <directory> <extension>
```

Например:

```bash
./cleanup.sh ./downloads .log
```

- Удаление нескольких типов файлов

Можно передать несколько расширений:

```bash
./cleanup.sh ./downloads .tmp .log .cache
```

В этом случае будут удалены файлы с расширениями .tmp, .log и .cache.
**Важно: расширение следует указывать с точкой (.tmp, .log, .cache).**

Примеры

- Удалить временные файлы:

```bash
./cleanup.sh /var/tmp
```

- Удалить лог-файлы:

```bash
./cleanup.sh ./project .log
```

- Удалить временные файлы и логи:

```bash
./cleanup.sh ./project .tmp .log
```

Пример результата:

```bash
Number of deleted files: 15
```

## Обработка ошибок

Если директория не указана:

```bash
Error: Please specify a directory.
Usage: ./cleanup.sh <directory> [extension1] [extension2] ...
```

Если директория не существует:

```bash
Error: Directory '/path/to/directory' does not exist.
```

В этих случаях скрипт завершает работу с кодом 1.

## Как это работает

1. Скрипт получает путь к директории из первого аргумента.
2. Остальные аргументы используются как расширения файлов.
3. Если расширения не указаны, используется .tmp.
4. Команда find рекурсивно ищет подходящие файлы.
5. Найденные файлы удаляются с помощью rm.
6. В конце выводится количество успешно удалённых файлов.

## Предупреждение

**Удаление выполняется безвозвратно с помощью rm.
Перед запуском убедитесь, что указали правильную директорию и расширения файлов.**

Например:

```bash
./cleanup.sh /home/user .log
```

удалит все .log файлы внутри /home/user, включая файлы во вложенных директориях.
