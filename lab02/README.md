# Лабораторная работа № 2. Взаимодействие с Web API на Python

## Назначение

Скрипт `currency_exchange_rate.py` запрашивает курс валют на указанную дату у приложенного PHP-сервиса. Полный ответ сервера сохраняется в JSON в каталоге `data` в корне репозитория. Ошибки выводятся в консоль и записываются в корневой `error.log` с датой и временем.

## Зависимости и запуск сервиса

Требуется Python 3.10 или новее. Сторонние библиотеки Python не нужны: используются модули стандартной библиотеки. Установка через pip не требуется.

Для основного способа запуска сервиса необходимы Docker и Docker Compose. Исходные PHP-файлы и данные задания собраны в `lab02/service`, серверный код не изменён.

Из корня репозитория выполните в PowerShell:

```powershell
Copy-Item lab02/service/sample.env lab02/service/.env
docker compose -f lab02/service/docker-compose.yaml up -d
$env:API_KEY = 'EXAMPLE_API_KEY'
python lab02/currency_exchange_rate.py USD EUR 2025-01-01
```

Значение `API_KEY` в окружении Python должно совпадать со значением в `service/.env`. Файл `.env` и журнал ошибок исключены из Git. Для остановки сервиса:

```powershell
docker compose -f lab02/service/docker-compose.yaml down
```

Альтернативный способ при наличии PHP 8.3: запустить в отдельном терминале из корня репозитория:

```powershell
$env:API_KEY = 'EXAMPLE_API_KEY'
php -S 127.0.0.1:8080 -t lab02/service/app
```

В Linux/macOS переменная задаётся командой `export API_KEY=EXAMPLE_API_KEY`, а Python обычно вызывается как `python3`.

## Параметры и примеры

```text
python lab02/currency_exchange_rate.py ИСХОДНАЯ_ВАЛЮТА ЦЕЛЕВАЯ_ВАЛЮТА ГГГГ-ММ-ДД [--url АДРЕС]
```

Поддерживаемые сервером коды: MDL, USD, EUR, RON, RUS, UAH. Регистр ввода не важен. Даты допустимы с 2025-01-01 по 2025-09-15 включительно. Адрес по умолчанию — `http://localhost:8080/`; его можно изменить параметром `--url` или переменной `API_URL`.

```powershell
python lab02/currency_exchange_rate.py EUR MDL 2025-09-15
python lab02/currency_exchange_rate.py usd eur 2025-01-01
python lab02/currency_exchange_rate.py USD EUR 2025-01-31 --url http://127.0.0.1:8080/
python lab02/currency_exchange_rate.py --help
```

Результат первого запроса USD/EUR сохраняется в `data/USD_EUR_2025-01-01.json`. Повторный запрос с той же парой и датой перезаписывает файл. Расположение `data` и `error.log` вычисляется относительно скрипта, поэтому не зависит от текущего рабочего каталога. Код завершения: 0 — успех, 1 — ошибка.

## Запуск для пяти равноотстоящих дат

Период: 1 января — 1 мая 2025 года, шаг — ровно 30 календарных дней.

```powershell
$dates = '2025-01-01', '2025-01-31', '2025-03-02', '2025-04-01', '2025-05-01'
foreach ($day in $dates) {
    python lab02/currency_exchange_rate.py USD EUR $day
}
```

## Структура скрипта

- `parse_args()` читает аргументы, нормализует коды валют, проверяет календарную дату, период данных и адрес сервиса.
- `get_exchange_rate()` отправляет POST-запрос: `from`, `to`, `date` находятся в строке URL, а `key` — в теле формы. Тайм-аут запроса — 15 секунд. Функция проверяет HTTP-ошибки, JSON, поле `error`, соответствие ответа запросу и числовой курс.
- `save_data()` создаёт корневой каталог `data` и сохраняет полный ответ в UTF-8 с отступами.
- `main()` связывает этапы, сообщает результат, обрабатывает ошибки и записывает журнал. Ключ API скрывается в сообщениях.

## Проверка ошибок

```powershell
python lab02/currency_exchange_rate.py AAA EUR 2025-01-01
python lab02/currency_exchange_rate.py USD EUR 2025-02-30
python lab02/currency_exchange_rate.py USD EUR 2025-09-16
python lab02/currency_exchange_rate.py RUS EUR 2025-01-01
python lab02/currency_exchange_rate.py USD EUR 2025-01-01 --url http://127.0.0.1:1/
Get-Content error.log
```

## Особенности исходного сервиса

1. Ошибки авторизации и валют могут возвращаться с HTTP 200. Поэтому клиент обязательно проверяет поле `error`.
2. Сервер объявляет код `RUS`, но данные содержат `rub`. Запрос с RUS завершается ошибкой сервиса, которую клиент корректно регистрирует. Код RUB сервер не принимает.
3. Если дата отсутствует в данных, сервер использует последнюю запись. Клиент запрещает даты за пределами периода задания. По ответу невозможно обнаружить пропуск отдельной даты внутри периода: сервер возвращает запрошенную дату даже при подстановке.
4. Сервер вычисляет `ставка_целевой / ставка_исходной`. Поскольку исходные ставки выражены в MDL за единицу валюты, обычная конвертация требует обратного отношения. Клиент сохраняет именно ответ учебного API, не исправляя серверную формулу. Например, USD/EUR на 2025-01-01 — около 1,044996, что не следует трактовать как корректный рыночный курс конвертации USD в EUR.
